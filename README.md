# Fest-in-a-Box

**One Brief. Every Asset. Ready to Publish.**

Fest-in-a-Box is an AI-powered event management toolkit built for student clubs. Fill out a single event brief and receive a complete creative pack — poster copy, social media captions, emcee script, announcement emails, participation certificate, event schedule, and a QR-code registration page — all generated in under 60 seconds.

🌐 **Live Demo:** https://fest-in-a-box.onrender.com

---

## The Problem

Student club organisers spend 5–10 hours per event bouncing between Canva, Google Docs, WhatsApp, and email clients just to produce basic event collateral. There is no unified tool designed specifically for the college event workflow. Most AI tools are generic — they don't understand the structure of a student event brief or produce the right set of outputs.

## The Solution

Fest-in-a-Box takes a structured event brief (name, theme, venue, date, vibe, organiser details) and uses a large language model to generate all required event assets simultaneously. The output is not generic — each asset is contextually aware of every other field in the brief. The emcee script knows the venue. The email knows the club name. The certificate knows the organiser.

---

## How It Works

```
User fills event brief
        ↓
FastAPI backend validates and sends to Groq AI (llama-3.3-70b)
        ↓
AI generates 6 text assets in one structured JSON response
        ↓
Pollinations.ai generates an event-specific poster image (flux model)
        ↓
QR code is auto-generated linking to the registration page
        ↓
Full pack is saved to Supabase and displayed to the user
        ↓
User can edit, regenerate, share, and view registrations
```

## Generated Assets Explained

1. **Poster Copy** — Headline, subheading, event details, CTA, and hashtags
2. **Social Media Pack** — Instagram caption with hashtags + WhatsApp broadcast message
3. **Emcee Script** — Opening intro, crowd warm-up, segment transitions, closing statement
4. **Announcement Emails** — Separate versions for faculty (formal) and students (casual)
5. **Participation Certificate** — Print-ready template with signatory block, 3 visual styles
6. **Event Schedule** — Time-slotted agenda with activity descriptions
7. **QR Signup Page** — Public URL with registration form; registrations visible to organiser
8. **AI Poster Art** — Photorealistic event background image specific to theme and vibe

## Local Setup

### Prerequisites
- Python 3.11+
- Node.js 18+
- Supabase project
- Groq API key (free at console.groq.com)

### Backend
```bash
cd backend
pip install -r requirements.txt
# Create .env with variables listed below
uvicorn main:app --reload
```

### Frontend
```bash
cd frontend
npm install
# Create .env.local with variables listed below
npm run dev
```

### Database
Run `backend/supabase_schema.sql` in the Supabase SQL Editor to create all required tables.
